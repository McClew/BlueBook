## Network Cabling Standards

Network cabling standards define the physical infrastructure that enables data transmission across computer networks. <mark style="color:$primary;">**These standards specify the construction, performance characteristics and maximum transmission speeds for different cable types.**</mark>

{% hint style="info" icon="ethernet" %}
Importance

Understanding cabling standards is essential as the physical later (Layer 1) of the OSI model foms the foundation on which all network security depends. <mark style="color:$primary;">Weak or outdated cabling infrastructure can create vulnerabilities that compromise network integrity and performance.</mark>
{% endhint %}

The category rating system for <mark style="color:$primary;">**Unshielded Twisted Pair (UTP)**</mark> cable provides a standardised way to classify cables based on their construction quality and transmission capabilities. Each category represents improvements on shielding, twist rates and overall construction that enables higher data tranmission speeds. <mark style="color:$primary;">**These improvements directly impact the reliability and speed of network communications.**</mark>
